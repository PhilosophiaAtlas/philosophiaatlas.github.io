# Alpha.10 Knowledge Graph
The static private graph derives from article links, category membership and category parent relations. The browser adds local IndexedDB notes, their source articles and explicit note links; note data is not uploaded. Node identifiers are namespaced by type.
The graph uses deterministic radial neighborhoods, directed edges, type and relation filters, accent-insensitive search, zoom, pan and a textual alternative. The overview and neighborhoods are capped at 60 visible nodes by default (algorithm hard cap 120). The full data is searchable; depth is 1–3. Layout does not imply semantic similarity, evidence strength or philosophical agreement. Missing links are omitted. No force simulation, external service or third-party graph dependency is required.
